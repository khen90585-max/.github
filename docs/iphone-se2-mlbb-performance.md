# iPhone SE (2nd gen) Mobile Legends performance setup

This checklist helps reduce lag and improve stability on iPhone SE 2 while playing Mobile Legends.

## Device setup
- Update iOS to the latest version supported by your device.
- Keep at least 8-10 GB free storage.
- Disable Low Power Mode while gaming.
- Close background apps before launching the game.

## Network setup (Wi-Fi and mobile data)
- Prefer 5 GHz Wi-Fi over 2.4 GHz when near the router.
- Place the router in open space and stay within good signal range.
- If Wi-Fi is unstable, test mobile data and pick the lower ping option.
- Disable large downloads/streaming on the same network while playing.

## In-game settings (Mobile Legends)
- Graphics: Smooth
- Frame Rate: High (or Ultra if available and stable)
- Shadow: Off
- HD mode and extra effects: Off
- Enable battlefield optimization / performance mode if available.

## Notes about 144 FPS
iPhone SE 2 hardware and game support usually cap frame rate below 144 FPS. Prioritize stable frame rate and low ping rather than forcing unsupported FPS values.

## Hero/Gameplay mode tips
- Use lower effects during team fights for more stable performance.
- Reboot the phone before long ranked sessions.
- Keep phone cool; remove thick case during play if device overheats.
